# Rotno Fashion House — সেটআপ ও ডিপ্লয় গাইড

এই প্রজেক্টে ৩টা অংশ আছে:
- `customer/` — কাস্টমারদের জন্য মূল ওয়েবসাইট
- `admin/` — শুধু আপনার জন্য, আলাদা লিংকে থাকবে, পাসওয়ার্ড দিয়ে লক করা
- `supabase-schema.sql` — ডাটাবেস তৈরির কোড

কোনো টাকা/কার্ড ছাড়াই পুরোটা ফ্রি-তে করা সম্ভব। ধাপে ধাপে নিচে দেওয়া হলো।

---

## ধাপ ১: Supabase অ্যাকাউন্ট ও ডাটাবেস তৈরি

1. https://supabase.com এ যান, **Sign up** করুন (ইমেইল বা Google দিয়ে) — কার্ড লাগবে না
2. **New Project** ক্লিক করুন, একটা নাম দিন (যেমন `rotno-fashion-house`), পাসওয়ার্ড সেট করুন (এটা মনে রাখুন, ডাটাবেস পাসওয়ার্ড — অ্যাডমিন লগইন পাসওয়ার্ড থেকে আলাদা)
3. Region হিসেবে **Singapore** বেছে নিন (বাংলাদেশ থেকে সবচেয়ে কাছে, দ্রুত লোড হবে)
4. প্রজেক্ট তৈরি হতে ১-২ মিনিট লাগবে

### ডাটাবেস টেবিল তৈরি করা
1. বাম পাশের মেনু থেকে **SQL Editor** এ যান
2. **New query** ক্লিক করুন
3. `supabase-schema.sql` ফাইলের পুরো কনটেন্ট কপি করে পেস্ট করুন
4. **Run** বাটনে ক্লিক করুন — সব টেবিল ও স্টোরেজ বাকেট তৈরি হয়ে যাবে

### API কী সংগ্রহ করা
1. বাম মেনুর নিচে **Project Settings** (⚙️ আইকন) > **API** এ যান
2. **Project URL** কপি করুন (যেমন `https://xxxxx.supabase.co`)
3. **anon public** কী কপি করুন (এটা একটা লম্বা টেক্সট)

এই দুটো জিনিস এখন লাগবে পরের ধাপে।

## ধাপ ২: কোডে Supabase তথ্য বসানো

`customer/config.js` ফাইল খুলুন, এভাবে বদলান:
```javascript
const SUPABASE_URL = "আপনার Project URL এখানে";
const SUPABASE_ANON_KEY = "আপনার anon key এখানে";
```

`admin/config.js` ফাইলেও **একই তথ্য** বসান (দুটো ফাইলেই একই Supabase প্রজেক্ট ব্যবহার হবে)।

`admin/index.html` ফাইলে খুঁজে বের করুন এই লাইন:
```javascript
const ADMIN_PASSWORD = "rotno2026";
```
চাইলে `"rotno2026"` বদলে নিজের পাসওয়ার্ড বসান।

## ধাপ ৩: GitHub-এ কোড আপলোড করা

1. https://github.com এ অ্যাকাউন্ট খুলুন (না থাকলে)
2. **New repository** বানান, নাম দিন যেমন `rotno-fashion-house`
3. এই পুরো ফোল্ডারটা (customer, admin, supabase-schema.sql সহ) আপলোড করুন:
   - সহজ উপায়: GitHub-এর ওয়েবসাইটে repo খুলে **Add file > Upload files** দিয়ে সব ফাইল/ফোল্ডার টেনে দিন

## ধাপ ৪: Vercel দিয়ে ফ্রি হোস্ট করা (দুইবার — কাস্টমার ও অ্যাডমিন আলাদা)

### কাস্টমার সাইট ডিপ্লয়
1. https://vercel.com এ যান, GitHub দিয়ে সাইন আপ করুন
2. **Add New > Project** ক্লিক করুন
3. আপনার `rotno-fashion-house` রিপো সিলেক্ট করুন
4. **Root Directory** তে ক্লিক করে `customer` সিলেক্ট করুন
5. **Deploy** চাপুন — ১-২ মিনিটে একটা লিংক পাবেন, যেমন `rotno-fashion-house.vercel.app`

### অ্যাডমিন সাইট ডিপ্লয়
একই রিপো দিয়ে **আবার নতুন প্রজেক্ট** বানান:
1. **Add New > Project** আবার ক্লিক করুন
2. একই রিপো সিলেক্ট করুন
3. এবার **Root Directory** তে `admin` সিলেক্ট করুন
4. প্রজেক্টের নাম বদলে দিন (যেমন `rotno-admin`)
5. **Deploy** চাপুন — আলাদা একটা লিংক পাবেন, যেমন `rotno-admin.vercel.app`

এখন আপনার ২টা আলাদা লিংক আছে — একটা কাস্টমারদের জন্য শেয়ার করবেন (Facebook Ads, বায়ো লিংক), আরেকটা শুধু আপনি নিজে ব্যবহার করবেন, কাউকে দেবেন না।
